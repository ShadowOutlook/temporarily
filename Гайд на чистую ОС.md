3. **Заходим в С:\Program Files\WindowsApp для просмотра всех UWP-приложений**
https://microsin.net/adminstuff/windows/access-windowsapps-folder-windows-10.html
```bash
Чтобы отобразить папку необходимо в верхнем меню 'Просмотреть' выбрать 'Показать' 'Скрытые элементы' (с галочкой у этой опции)
```

```bash
После нажать по папке 'WindowsApp' левой кнопкой мыши (ЛКМ) выбрать 'Свойства' перейти на закладку 'Безопасность' (Security), и кликнуть на кнопку 'Advanced'
```

```bash
Откроется окно диалога Advanced Security Settings, кликните в нем на ссылку 'Change'.
```

```bash
Откроется окно запроса подтверждения UAC (User Access Control). Просто кликните на кнопку "Yes" для продолжения.
```

```bash
Окно покажет все разрешения, которые в настоящий момент настроены для папки WindowsApps. Как Вы можете видеть, эта папка относится к системе, и поэтому Вам просто так нельзя получить к ней доступ. Чтобы изменить это, кликните на ссылку Change, которая находится рядом с текстом "Owner: TrustedInstaller", обозначающим текущего владельца папки.

Откроется окно выбора пользователя или группы "Select User or Group". Здесь введите свое имя пользователя с правами администратора, и кликните кнопку "Check Names". Это действие автоматически заполнит имя объекта.

Кликните на кнопку OK для продолжения.
```

```bash
В основном окне Вы увидите, что владелец папки поменялся на указанную Вами учетную запись администратора. Перед тем, как применить изменения, установите галочку "Replace owner on sub containers and objects", иначе не получите полный доступ над содержимым папки WindowsApps.

После этого кликните на кнопку OK для сохранения изменений.

Windows начнет менять права доступа на содержимом WindowsApps, этот процесс может занять некоторое время.

Тем же самым способом Вы можете получить полный доступ к любой другой папке Program Files, пока у Вас есть права администратора.
```

4. **Подучаем список UWP-приложений которые без веских на то причин удалять нельзя, да и вообще никак нельзя для работоспособности ОС**

Get-AppxPackage| ? { $_.SignatureKind -eq "System" }|select Name,InstallLocation
