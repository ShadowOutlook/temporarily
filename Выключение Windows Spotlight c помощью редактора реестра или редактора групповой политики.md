
## Отключите функции Windows Spotlight с помощью редактора групповой политики

Чтобы отключить функции Windows Spotlight в Windows 11/10, выполните следующие шаги.

1. Нажмите Win+R, чтобы открыть окно Выполнить.
2. Введите _gpedit.msc_ и нажмите кнопку Enter.
3. Перейдите к _Облачному содержимому_ в _Конфигурации пользователя_.
4. Дважды щелкните на _Отключить все функции Windows spotlight_.
5. Выберите включенный вариант.
6. Нажмите кнопки _Применить_ и _ОК_.

Давайте подробно рассмотрим эти шаги.

`https://ru.windows.day/?p=43583`

Чтобы начать, откройте редактор локальной групповой политики. Для этого нажмите **Win+R**, чтобы открыть окно выполнения, введите `gpedit.msc`, и нажмите Enter. Теперь перейдите по следующему пути-

```sql
User Configuration > Administrative Templates > Windows Components > Cloud Content
```

В папке _Облачное содержимое_ вы увидите параметр под названием **Отключить все функции Windows Spotlight**. Дважды щелкните по нему и выберите вариант **Включено**.

Затем нажмите на кнопки **Применить** и **ОК**, соответственно.

После этого Windows Spotlight на экране блокировки, советы Windows, потребительские функции Microsoft и другие опции станут невидимыми.

**Связано**: Windows Spotlight не работает.

## Отключите функции Windows Spotlight с помощью редактора реестра

`https://ru.windows.day/?p=43583`

Чтобы отключить функции Windows Spotlight в Windows 10 с помощью редактора реестра, выполните следующие шаги -

1. Искать _regedit_ в строке поиска на панели задач.
2. Нажмите на _Редактор реестра_ в результатах поиска.
3. Нажмите кнопку _Да_ в запросе UAC.
4. Перейдите в _CloudContent_ в _HKCU_.
5. Щелкните правой кнопкой мыши на CloudContent > Новый > Значение DWORD (32-битное).
6. Назовите это _DisableWindowsSpotlightFeatures_.
7. Дважды щелкните на DisableWindowsSpotlightFeatures и установите значение данных как _1_.
8. Нажмите _ОК_, чтобы сохранить изменения.

Продолжайте читать, чтобы узнать больше об этих шагах.

Перед тем как начать, вам следует создать точку восстановления системы и сохранить все файлы реестра на всякий случай.

Сначала найдите `regedit` в строке поиска на панели задач, щелкните на _Редакторе реестра_ в результате поиска. Затем выберите кнопку **Да** в запросе UAC и перейдите по следующему пути -

```undefined
HKEY_CURRENT_USER\SOFTWARE\Policies\Microsoft\Windows\CloudContent
```

Щелкните правой кнопкой мыши по CloudContent и выберите **Создать > Значение DWORD (32-разрядное)**. Затем назовите его **DisableWindowsSpotlightFeatures**.

После этого дважды щелкните по DisableWindowsSpotlightFeatures, установите значение данных на **1** и нажмите кнопку **OK**, чтобы сохранить изменения.

На этом всё! Надеюсь, этот гид вам поможет.
